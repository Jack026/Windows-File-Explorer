Windows File Explorer Icon Pack

Contents
- Windows-File-Explorer.ico: multi-resolution Windows icon (16 to 256 px).
- png/: individual transparent PNGs at 28 common sizes (16 to 1024 px).
- tauri/: commonly used Tauri icon assets (32x32, 128x128, 128x128@2x, icon.png, icon.ico).
- master-transparent-1254.png: original transparent master image.

All images are square RGBA PNGs and retain the transparent background.
Use Windows-File-Explorer.ico for Windows executable and installer icons.
Use the files in tauri/ for a Tauri app icon set.
